# API Genie for Scoop

The [Scoop](https://scoop.sh) bucket of the [API Genie](https://apigenie.pl) CLI. One install gives you the five command-line tools: `apigenie`, `apigenie-generator`, `apigenie-server`, `apigenie-catalog` and `apigenie-mcp`.

    scoop bucket add apigenie https://github.com/mykulyak/scoop-apigenie
    scoop install apigenie
    apigenie --version

`scoop update apigenie` installs the latest release. The release tool updates `bucket/apigenie.json` with each release of [mykulyak/api-genie](https://github.com/mykulyak/api-genie/releases).
